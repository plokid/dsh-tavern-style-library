# DSH Tavern Style Library

**给 [DSH Tavern](https://github.com/flizzywine/dsh-tavern) 用的参考样文插件。** 把喜欢的文章、小说摘成片段存进「样文库」，按笔调打标签；游玩时选定一个库，每轮正文请求都会带上其中一段原文，让模型照着这个笔调写。

它不检索、不改写、不总结。摘录是什么，注入的就是什么——选中的那段原文，逐字进入上下文。

库攒够了，还可以让它**提炼成一张风格卡**：九个维度的量化观察、写作基因、铁律、禁用清单、AI 腔词表。摘录是证据，风格卡是规则；两个一起给，模型既看得到样子，也知道边界在哪。

```
┌─ 摘录的样文 ─────────────────┐
│ 冷峻 / 留白 / 短句            │   ← 笔调标签
│ 「雪落在刀鞘上，没有声音。」   │
└─────────────┬────────────────┘
              │ 每轮换一段
              ▼
┌─ 本轮正文请求 ─────────────────────┐
│ 【文风参考 · 冷峻武侠 · 风格卡】      │
│ ■ 风格卡：句法/词汇/对白…九维观察     │
│   写作基因、铁律、从不出现的东西       │
│ 参考原文：雪落在刀鞘上，没有声音。      │
└──────────────────────────────────┘
```

## 为什么用它

内置的「文风联想」已经是对的路子：把一段笔调相近的小说范文放进正文请求，让模型照这个笔调写。差别在于那段范文不受控——它贴合的是上一轮的场景情绪，不是需要固定的笔调；每轮自动换，无法指定其中某一段；而且不是逐字原文，是模型凭记忆复述的，节奏和用词有损耗。

样文库补的是另一半：**范文由使用者自己挑、逐字保存、自己决定每轮用哪一段。** 注入的是人工审过的原文，不是复述。顺带还省掉了每轮挑选段的那次后台调用——这里只是在取已经存好的文字。

剩下的工作量只有一件事：**审**那段文字算不算想要的笔调。这个判断模型替代不了。

## 用它能做什么

- **让模型稳定地写出指定笔调。** 不用反复解释「再冷一点、再克制一点」，直接给一段范本，而且这段范本是逐字的原文。
- **同一局里换着用。** 一段写打斗、一段写对话，逐轮轮换，不让笔调从头到尾一个味。
- **临时换笔调不用开面板。** 正文里多写一句 `#文风 冷峻`，这一轮就换那个笔调。
- **存一次，所有对局都能用。** 样文库不在某一局里，建好之后哪个存档都能选。
- **整本书交给 Agent。** 引用材料说一句话，它会切段、打标签、批量存进去。
- **从「像」到「稳」。** 摘录只给样子，风格卡给规则。嫌照着摘录写还是跑偏时，提炼一张卡，把「必须做到」和「绝不能出现」写清楚。

## 功能

- **笔调标签。** 库和单条样文都能打标签，内置一批偏笔调的（冷峻、留白、短句、文白…），也可以自己加、自己改、自己删。
- **风格卡。** 把整库摘录提炼成九个维度的量化观察 + 写作基因 + 铁律 + 禁用清单 + AI 腔词表。可以面板上一键提炼，也可以让 Agent 按 Skill 分析。见[下面那一节](#风格卡把摘录提炼成规则)。
- **三种注入方式。** 只用摘录（默认，和以前一样）、摘录＋风格卡、只用风格卡。每个库单独设。
- **逐轮轮换。** 和库标签有交集的样文优先进入候选池，在池内轮换；没有交集就整库轮换。第 1 轮用第 1 段，走完回到开头。同一轮重试不跳段，回退到旧轮次拿到的也是当时那段。
- **换一段。** 状态页或面板里点一下，从下一轮起改用下一段。
- **钉住某条。** 「手动选择」页点某一条，之后固定用它，不再轮换。
- **临时指定。** 正文框里写 `#文风 冷峻`，本轮按这个标签找库，优先级高于本局选中。
- **切段导入。** 粘一整章进来，按空行／段落自动切开，勾选要留的段一起存。
- **AI 打标签。** 调用本局后台模型给出标签建议，省去手动挑选。
- **搜索。** 列表页顶部搜索框，扫库名、标签、备注和样文原文。搜到样文时会把命中的**具体条目**摘出来单独列出（带库名、段号、出处和原文），可以直接固定给本局，或跳到所在库。
- **标签页。** 顶部列出标签池概况（几个、几个在用），每个标签标出被几个库或样文用到、共几处。改名会同步改掉所有引用。
- **删除都要二次确认。** 删库、删标签、删单条样文、清风格卡，第一次点「删除」只会在原地展开一条确认，写清删掉的是什么、会连带清掉哪些引用，再点一次才真删。

## 风格卡：把摘录提炼成规则

摘录告诉模型「长这样」，但它不知道哪些是必须的、哪些是这一次的即兴。风格卡补的是这件事：把整库的文字分析成一张能照着写、也能自检的卡。

### 九个维度

| 维度 | 量什么 |
| --- | --- |
| 词汇 | 高频词、这本书独有的词、固定搭配、用词质感 |
| 句法 | 平均句长、长短句分布、标点指纹、段落节奏 |
| 语气 | 口语化程度、冷热、断言强弱、句长波动 |
| 篇章 | 开头怎么起、场景怎么推进、在哪收 |
| 修辞 | 比喻密度与取材、排比、设问、具体与抽象的比例 |
| 情感 | 极性分布、情绪弧线、克制度 |
| 视角 | 人称、聚焦方式、价值词 |
| 感官 | 视觉／听觉／触觉各占多少，有没有通感 |
| 对白 | 对白多长、有没有提示语、不同人怎么区分 |

卡里除了九个维度，还有四样东西：

- **写作基因** 3～5 条：至少由两个维度共同支撑、删掉就不像了的特征。
- **铁律** 6～10 条：落到操作层，写完回头看一眼就知道有没有做到。
- **从不出现** 5～10 条：这段文字绝不做的事。这一项比正面特征更能定边界。
- **AI 腔词表**：「不由得」「心中五味杂陈」这类套话，一个都不许出现。

### 怎么提炼

**面板上：** 打开库 → 「AI 提炼风格卡」。用本局的后台模型跑一次，结果存进库里。

**让 Agent 做：** 在卡片工作台说「把『冷峻武侠』这个库提炼成风格卡」。它会按 `style-library` 这个 Skill 的流程分析，再调 `style_card_save` 存进来。同一个 Skill 也负责建库——说「用这本书建一个库」时它走的是同一条流程的前半段。分析框架和阈值在 `skills/style-library/references/` 里。

两条路都可以反复跑。**有旧卡再做一次是覆盖**，所以想保留手改的内容，就让 Agent 走增量修订（它会先 `style_card_get` 看一眼旧卡）。

### 三种注入方式

| 方式 | 每轮注入 | 适合 |
| --- | --- | --- |
| 只用一段摘录 | 原文 | 默认。只想让模型看到样子 |
| 摘录＋风格卡 | 规则 + 原文 | 最稳，token 也最多 |
| 只用风格卡 | 只有卡 | 摘录会带偏剧情、但规则想要的时候 |

改完立刻生效，不用再点保存。方式在库的编辑页里选。

**注进去的是卡的「条目版」，不是整张卡。** 九个维度各一行、基因一行、铁律一行、禁用一行、AI 腔一行，加起来约两千字以内——卡里还存着一句「指纹小结」，那是给人看和给导出的 Prompt 用的，不进每轮注入（它和维度条目说的是同一件事，重复一遍只是多花 token）。

### 试写与导出

- **试写一段**：不给原文，只按卡写 200～300 字，再让模型自评贴合度。像不像自己看一眼——这是唯一没法自动化的判断。**试写不存进卡里**：只在面板上显示这一次的结果，重开面板就没了，卡的体积也不会越试越大。
- **导出 Prompt**：把卡拼成一段自包含的 Prompt，可以直接粘给任何模型，不依赖这个插件。


## 安装

**前提：** 已经装好 DSH Tavern，并且版本足够新（插件接口 ≥ 2）。

插件不在 npm 上，把整个文件夹放进 Tavern 数据目录的 `plugins/` 即可。

**确认安装位置：** Tavern 数据目录下已有 `plugins/` 文件夹，放进其中、与其他插件并列。

```sh
git clone https://github.com/plokid/dsh-tavern-style-library.git \
  "$DSH_HOME/profile-data/tavern/data/plugins/dsh-tavern-style-library"
```

没设 `DSH_HOME` 时，默认位置是 `~/.dsh/profile-data/tavern/data/plugins/`。

不使用 git 时，下载 ZIP 解压后整体移入：

```sh
curl -L https://github.com/plokid/dsh-tavern-style-library/archive/refs/heads/main.zip \
  -o /tmp/style-library.zip
unzip /tmp/style-library.zip -d /tmp/
mv /tmp/dsh-tavern-style-library-main "$DSH_HOME/profile-data/tavern/data/plugins/dsh-tavern-style-library"
```

装好后刷新一次页面即可，不需要打包，也不用改 Tavern 的任何文件。

**更新：** 进插件目录 `git pull`，然后重启 DSH。

## 第一次用

### 建一个库

**少量、单条地贴**——侧栏「＋」→「插件」→「样文库」→ 右上「新建」，填名称、选几个笔调标签，然后二选一：

- **从长文切段**：把一整章粘进去，选每段字数，「切段」→ 勾选要留的 →「存入」。可以逐段或整批「AI 打标签」。
- **单条添加**：粘一小段，手动选标签，「保存样文」。

**整本、批量交给 Agent**——一次对话走完：

1. 在「剧本与素材库」引用要用的材料。
2. 到卡片工作台跟 Agent 说：「用我引用的这本书建一个样文库，叫『冷峻武侠』」。
3. Agent 会先拟一批笔调标签，列出来等确认；增删改之后，它才切段和打标签。
4. 存档完成后它会问一句「要不要现在提炼风格卡」。要，就接着做；不要，就是个只有摘录的库，之后随时能补。
5. 提炼完它会问注入方式（摘录 / 摘录＋卡 / 只用卡），选完存好，游玩时选中它生效。

建库和提炼是同一个 Skill（`style-library`）的两段，不用记两个名字。

### 开一局用上它

在侧栏面板点「本局使用」。之后每轮正文请求都会带上这个库里的一段（提炼了风格卡并打开之后，规则也会一起带上）。

「酒馆状态」页会多出「下一轮样文笔调」一节：标题行右侧是段号和出处，下面两行截断的引文，点一下展开全文；右侧「换一段」立刻跳到下一段。库里开了「只用风格卡」时，这一段显示的是卡里的前几条观察，也没有「换一段」——没有摘录可换。

想临时换笔调，在正文框里写 `#文风 冷峻`，这一轮就按这个标签找库。

### 界面上的两处入口

| 位置 | 能做什么 |
| --- | --- |
| 侧栏「＋」→「插件」→「样文库」 | 管理库和样文、切段导入、搜索、标签管理、手动选择、提炼风格卡、预览下一轮 |
| 「酒馆状态」页的「下一轮样文笔调」 | 看这一轮用哪一段、出处是什么，直接「换一段」 |

入口在侧栏的「插件」组里。库多、样文多时内容区会自己滚动；子页面左上角是「← 返回」，回到列表页。

## 和「文风联想」的关系

两者往正文里放的是同一类东西——一段范文 + 一句「只借笔调」。**同时开着会互相干扰**，建议二选一。

| | 文风联想（内置） | 本插件 |
| --- | --- | --- |
| 范文来源 | 后台模型按上一轮的题材情绪挑，多为凭记忆复述 | 自己摘录的原文，逐字 |
| 谁决定用哪段 | 每轮自动换 | 本局选定的库，按轮次轮换，可钉住 |
| 能不能固定一段 | 不能 | 能，「钉住」 |
| 模型调用 | 每轮多一次（跑挑选） | 没有（提炼风格卡那次不算，那是按需的） |
| 注入量 | 约 100～400 字 | 摘录约 2000 字；带风格卡时再多约 2600 字 |

内置那套的优势是零维护——不需要准备任何材料，开启开关即可。本插件多一步（存摘录），换来的是对范文的完全控制。

插件拿不到「文风联想」的开关状态，没法自动让路，只能在设置里手动关掉它。

## 能存多少

**大概能存五六十条。** 具体看段落多长：一千五百字的能存 55 条左右，六百字的能存八九十条。这个量对「几个库、每个库十几段」的用法绰绰有余。

单库最多 40 条，最多 60 个库，单条 40～2000 字，标签池最多 200 个，每条样文最多打 12 个标签。真顶到总容量上限时，保存会明确报错，不会悄悄丢数据。

**风格卡另算。** 一个库一张卡，上限 24 KB（正常一张卡两三 KB，写满了大概 30 KB）。卡的解析结果会规整成固定形状，所以模型多写几条也不会把库撑坏——超了直接拒绝保存，并告诉你删几条。

样文库存在 Tavern 数据目录的 `plugin-data` 里，想备份直接复制整个 `plugin-data` 文件夹。

## 常见问题

| 情况 | 先检查什么 |
| --- | --- |
| 状态页那一节只显示提示、没有引文 | 这一局还没选库。提示下面有「去样文库选一段 →」，点进去选 |
| 「换一段」没反应 | 库里是不是只有一段；只有一段时无法轮换，会给出提示。库设成「只用风格卡」时也不会显示这个按钮 |
| 注入的内容没生效 | 本局是否点了「本局使用」；是否开着内置文风联想在抢位置（两者都给范文，会互相顶） |
| 「AI 打标签」报错 | 这一局是否配置了后台模型。手动打标签不受影响 |
| 「AI 提炼风格卡」报错 | 同上，要走后台模型；另外库里至少要有一条摘录 |
| 提炼了卡但感觉没变化 | 注入方式还是「只用一段摘录」。改成「摘录＋风格卡」或「只用风格卡」，改完立刻生效 |
| 卡里的条目和我的判断不一样 | 卡是模型按材料写的，不是真理。面板上改不了明细，可以让 Agent 走增量修订，或者重新提炼 |
| 标签选不中 | 标签是精确匹配，不做同义词归并。库里和样文要用同一个写法 |
| 保存时报容量超限 | 删掉一些样文，或缩短单条。参考上面「能存多少」 |
| 让 Agent 建库，只出来一两条 | 条数是按材料长度定的（大约每 1500 字一条），不是「挑最有代表性的几句」。材料长就该多出几条，只出一条说明它没读全，让它重新切 |
| 改名之后原来的标签还在 | 改名只把池子里这一个名字换掉，不会合并两个已存在的标签。目标名已存在时会直接拒绝，想合并就先删掉一个 |

## 还有哪些限制

- 样文是**摘录**，不是整本。单条上限 2000 字。
- 切段只保证长度合理（每段约 300～500 字），**笔调是否完整要自己看一眼**。段落被硬切在场景中间时，手动合并或换更大的段长。
- 轮换按轮次号算，回退到之前某一轮时拿到的还是原来那段——这是有意的，回退后的重写应当看到同样的参考。
- 「换一段」从下一轮起生效，不会改已经写好的正文。
- `#文风` 标记只认标签名，不做模糊匹配。标签写错会静默回退到本局选中的库。
- 风格卡是**整库一份**，不随对局变化：换一局、回退到哪一轮，用的都是同一张卡。
- 风格卡能提炼出规则，但**判断「像不像」还是人**。试写那个自评百分比是模型给自己打的分，只能当参考。
- 笔调参考只影响写作风格，不保证模型一定遵守；最终效果仍取决于所用模型与预设。
